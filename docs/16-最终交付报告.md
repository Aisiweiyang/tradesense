## 一、已实现功能

### P0（全部可用 ✅）
- **产品资料导入**：CSV/Excel 上传 → 表头自动映射（中英文别名 100+）→ 行级校验 → 重复 SKU 识别 → 预览确认 → 提交（新建/更新/失败明细）；模板下载、Excel 导出、批量启停、手工编辑
- **客户与询盘管理**：轻量 CRM（联系人/国家/来源/标签/阶段 9 档/可解释线索评分），询盘列表（搜索/筛选/分页）
- **多轮询盘解析**：规则引擎提取 17 类字段（中英文），多轮覆盖、否定、"无所谓"、矛盾、人工修正、锁定保护全部实现
- **结构化需求状态**：6 态状态机 + 全量修改历史 + 来源消息 + 置信度
- **产品匹配**：两阶段检索（同义词召回 + 确定性重排序），权重可配置，硬条件淘汰原因透明
- **智能追问**：每轮 1 主 + 3 次，法规/报价阻塞 > 矛盾 > 信息增益 > 偏好，附理由，去重
- **回复草稿**：10 场景 × 3 语气，EN 正文 + ZH 对照，事实溯源 + 人工确认清单
- **基础报价**：确定性计算（EXW/FOB/CIF/DDP），逐行来源、假设、缺失、风险；成本/建议/客户/批准四价分离；版本管理 + 人工批准门禁
- **跟进提醒**：今日/超期/报价后未回复/长期沉默/高意向/信息不完整，任务 CRUD + 理由
- **完整核心工作台**：询盘详情 8 区块（概览/对话/需求/追问/匹配/报价/回复/跟进）
- **本地一键启动**：`scripts/start_dev.bat|.sh`（实测）；演示数据 + 79 个自动化测试

## 二、核心业务流程（全部真实前后端 + 数据库，无假数据）

```
导入产品 → 粘贴英文询盘 → 识别语言+中文摘要 → 提取结构化需求
→ 标记缺失/矛盾/风险 → 匹配产品(可解释) → 推荐一个最值得问的问题
→ 生成中英文回复草稿 → 计算报价并显示依据 → 业务员编辑+人工确认
→ 记录跟进任务与客户阶段
```
API 级端到端测试 `test_full_core_flow` 覆盖全链路（含 blue→black 多轮修正历史）。

## 八、主要设计决策

1. **确定性优先**：价格/硬条件/完整度全部程序计算；AI 仅建议且需确认（`AI_PROVIDER=none` 全功能可用）
2. **人工权威**：锁定字段拒绝自动覆盖（locked_ignored 留痕）；正式报价/回复必须批准；系统永不自动发送
3. **解释性**：完整度给原因、匹配给分项+淘汰原因、追问给理由、报价给逐行来源、评分给因子
4. **模拟≠伪造**：连接器缺凭据时 `mode=simulated` + `not_authorized_simulated`，界面明确标注
5. **可解释状态机**：每字段独立状态机 + 全量历史，原始表达永不丢弃
6. SQLite 一键起步 + Alembic 兜底（create_all+stamp），PostgreSQL 生产路径清晰
