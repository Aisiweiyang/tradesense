# 02 · 本地启动

## 环境要求

- Windows 10/11（macOS/Linux 同样支持）
- Python 3.12/3.13（`py -3.13`）
- Node.js ≥ 18（推荐 20+）
- 可选：Docker（容器部署）、Ollama 或 OpenAI 兼容服务（AI 增强）

## 方式一：一键脚本

```bat
scripts\start_dev.bat     :: Windows
bash scripts/start_dev.sh # macOS/Linux
```

脚本幂等：已装过依赖/已初始化数据库时会跳过对应步骤。

## 方式二：手动

### 后端

```bash
cd backend
py -3.13 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python scripts\init_db.py
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

`init_db.py` 的行为：

1. `alembic upgrade head`（首选，支持后续升级）；
2. 失败则 `create_all` + `alembic stamp head`（保证全新环境可用）；
3. `ensure_seeded()`：仅在演示组织不存在时写入演示数据（幂等）。

### 前端

```bash
cd frontend
npm install
npm run dev      # 开发模式 http://127.0.0.1:5173，/api 代理到 8000
npm run build    # 生产构建到 dist/
npm run preview  # 本地预览构建结果（同样代理 /api）
```

## 环境变量

复制根目录 `.env.example` 到 `backend/.env` 后修改。常用项：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DATABASE_URL` | `sqlite:///./data/tradesense.db`（相对 backend/ 运行目录，自动创建） | 换 PostgreSQL：`postgresql+psycopg://user:pass@host/db` |
| `SECRET_KEY` | dev 值 | 生产必须修改 |
| `SEED_DEMO_DATA` | `1` | 生产置 0 |
| `AI_PROVIDER` | `none` | `openai_compat` / `ollama` |
| `CORS_ORIGINS` | localhost:5173 | JSON 数组格式 |

## 常见问题

**Q: 端口被占用**
后端：`--port 8001`（前端代理目标需同步改 `vite.config.ts`）；前端：`npm run dev -- --port 5174`。

**Q: pip 安装超时**
重试或使用镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。

**Q: 演示数据想重来**
停止后端 → 删除 `backend\data\` 目录 → 重新 `init_db.py`。

**Q: 数据库升级**
修改模型后：`alembic revision --autogenerate -m "描述"` → 检查生成的迁移 → `alembic upgrade head`。
