# 07 · 数据模型

全部业务表带 `org_id`（组织隔离），绝大多数带 `created_at/updated_at`。时间列使用 `TZDateTime`（保证读出的时间始终带 UTC 时区，SQLite/PG 行为一致）。

## 货件与单证域（第四阶段）

| 表 | 说明 |
| --- | --- |
| shipments | 货件号、订单、运输方式、港口对、Incoterms、ETD、截单时间、负责人、状态（7 档）、必备单证清单 JSON |
| documents | 货件单证：类型（发票/装箱单/提单/报关单/信用证/原产地证）、版本、文件、状态（上传/提取/待人工/核验/失败）、页数、文本层标记 |
| document_fields | 字段名、值、置信度、**证据页码+原文行**、来源（提取/人工）、修改人 |
| shipment_issues | 严重度、类型（冲突/缺失/低置信）、规则码、期望 vs 实际、证据 JSON、状态（open/adopted/manual_fixed/ignored/resolved）、处理人、理由 |
| doc_rule_configs | 规则按客户/全局启停与参数（如毛重允差） |

## 组织与用户

| 表 | 关键字段 | 说明 |
| --- | --- | --- |
| organizations | name, default_locale, settings_json | 租户 |
| users | email(唯一), password_hash, role, locale | owner/manager/member/viewer |
| roles | code, name | 角色定义（P2 细化权限） |

## 客户域

| 表 | 说明 |
| --- | --- |
| customers | 公司、国家、来源渠道、阶段(9 档)、标签、优先级、负责人、最后联系/下次跟进、**线索评分+因子**(可解释) |
| contacts | 联系人：姓名/邮箱/电话/WhatsApp/职位/主联系人 |

## 询盘域

| 表 | 说明 |
| --- | --- |
| inquiries | 标题、状态(open/clarifying/quoted/won/lost/spam)、语言、原文、summary_json、完整度、质量标记、来源渠道 |
| conversation_threads | 渠道会话（channel、external_account、external_session_id） |
| conversation_messages | 方向(in/out)、发送方、原文、解析结果 parse_json、external_message_id、内容哈希（ inquiries 内去重） |

## 需求状态域（算法核心）

| 表 | 说明 |
| --- | --- |
| requirement_states | 每个询盘一份状态（revision 递增） |
| requirement_slots | 每字段一行：raw/value/normalized/unit/**status**/confidence/来源消息/历史值 JSON/**locked**/confirmed |
| requirement_history | 全部变更：set/update/conflict/conflict_resolved/unconstrained/manual_set/**locked_ignored**/…，含 actor(system/human) |
| clarification_logs | 已推荐的追问：字段、中英文问题、理由、优先级、状态(open/answered/dismissed) |

槽位状态机：`unknown → active ⇄ replaced / unconstrained / conflicting / needs_confirmation`（详见《08-多轮状态算法》）。

## 产品域

| 表 | 说明 |
| --- | --- |
| products | SKU、中英文名、category(概念)、材质、规格、颜色、包装、MOQ、**阶梯价格 JSON**、币种、交期、定制、认证 JSON、keywords、**markets**、单重、data_source、is_active |
| product_variants | 变体（P2 扩展用） |
| suppliers | 名称、地区、类目、可靠性 0-1 |
| supplier_products | 供应商×产品成本/交期（比价基础） |
| certifications | 认证字典（代码/区域/说明） |

## 报价域

| 表 | 说明 |
| --- | --- |
| quotes | 询盘+产品+**版本号**、状态(draft/pending_approval/approved/rejected/superseded)、术语、币种、数量、**unit_cost(内部)/unit_price(建议)/customer_price(客户)/total**、breakdown/assumptions/missing/risks/exchange JSON、valid_until、**is_formal(仅人工批准)**、审批人/时间 |
| quote_items | 行项目（数量、成本、报价、小计、利润率） |
| price_rules | 机构级价格规则（margin/freight_zone/insurance/duty…） |

## 匹配与跟进

| 表 | 说明 |
| --- | --- |
| match_results | 批次 batch_no、rank、total_score、分项得分 JSON、met/unmet、excluded+原因、is_alternative、数据快照（来源/新鲜度） |
| follow_up_tasks | 标题、类型、due_at、状态(pending/done/snoozed/cancelled)、优先级、**reason_json(为什么建议)** |
| reply_drafts | 10 类场景、语气、EN/ZH 正文、变量、**facts_used**、**needs_confirmation**、状态(须 approved 才能标记已人工发送) |

## 连接器与系统

| 表 | 说明 |
| --- | --- |
| connector_accounts | 类型、名称、mode(live/simulated)、auth_state、状态、最后同步、错误 |
| external_messages | 渠道、外部账号/会话/消息 ID、发送方、原始/标准化内容、附件、内容哈希、处理状态、关联询盘、重试计数 |
| sync_cursors | 账号级同步游标 |
| sync_logs | 级别、事件、详情 JSON |
| knowledge_documents | 知识库（P2 预留） |
| audit_events | 用户、动作、实体、详情（敏感键脱敏） |

## 关系速览

```
Organization 1─* User / Customer / Product / Supplier / Inquiry / ...
Customer 1─* Contact 1─* Inquiry
Inquiry 1─1 RequirementState 1─* RequirementSlot
Inquiry 1─* ConversationThread 1─* ConversationMessage
Inquiry 1─* RequirementHistory / ClarificationLog / MatchResult / Quote / ReplyDraft / FollowUpTask
Product *─1 Supplier; Quote 1─* QuoteItem
ConnectorAccount 1─* ExternalMessage / SyncCursor / SyncLog
```
