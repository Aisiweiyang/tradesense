# 04 · 产品数据导入

首批外贸用户大多没有 API，只有 Excel/CSV。导入流程为**两步确认制**：预览校验 → 人工确认后才写入产品库。

## 支持格式

- `.csv`（UTF-8 / UTF-8-BOM / GBK 自动识别）
- `.xlsx` / `.xlsm`（取第一个工作表）
- 单文件 ≤ 10MB

## 标准字段

| 字段 | 常见表头别名 | 必填 | 说明 |
| --- | --- | --- | --- |
| sku | 货号/编码/型号/Item No | ✅ | 唯一标识，重复即报错/更新 |
| name_zh | 中文名称/品名 | 二选一 | |
| name_en | 英文名称/Product Name | 二选一 | |
| category | 类别/分类/品类 | 建议 | 无法识别时按名称自动归类（保温杯→insulated_bottle 等 11 类） |
| material | 材质/材料 | | 会做归一化（304不锈钢→stainless steel 304） |
| spec / size | 规格/容量/尺寸 | | 500ml、17oz 自动换算 ml |
| color | 颜色/可选颜色 | | |
| packaging | 包装/包装方式 | | |
| moq | 起订量/MOQ | | 默认 1 |
| price_tiers | 阶梯价/价格/单价 | 建议 | `500:3.2;1000:3.0;5000:2.8` 或单值 `2.5` |
| currency | 币种 | | USD/EUR/CNY…，默认 USD |
| lead_time_days | 交期/生产周期 | | 默认 30 |
| customization | 定制/工艺 | | logo/丝印/激光… |
| certifications | 认证/证书 | | FDA, LFGB, CE, RoHS, BPA-free, CA Prop 65… 自动归一化 |
| supplier_name | 供应商/工厂 | | 不存在会自动创建供应商 |
| markets | 市场/可售市场 | | ISO2 逗号分隔（如 `DE,FR,US`）；为空=不限制；用于匹配硬条件 |
| unit_weight_kg | 单重/重量 | | 用于海运费估算，缺失时按 0.35kg 估算并提示 |
| image_url / description / stock_status | 图片/描述/库存 | | |

完整别名表见 `backend/app/services/imports.py` 的 `HEADER_ALIASES`。

## 校验规则

每行独立校验，行级错误**不会阻塞其他行**：

- 缺 SKU、缺中英文名称 → ❌ 错误（该行跳过）
- MOQ/交期/重量无法解析为数字 → ❌ 错误 或 ⚠️ 警告（回退默认值）
- 阶梯价格无法解析 → ❌ 错误
- 文件内 SKU 重复 → ❌ 错误（标注冲突行号）
- SKU 已存在于产品库 → ⚠️ 警告（提交时**更新**原产品）
- 币种/认证无法识别 → ⚠️ 警告（回退默认/保留原文）

## 幂等与安全

- 预览令牌（token）15 分钟内有效，一次性使用；
- 提交时只处理预览通过的行，返回 `{created, updated, failed}` 明细；
- 导入动作写入审计日志。

## API

```http
GET  /api/imports/template          # 下载 CSV 模板
POST /api/imports/preview           # multipart 上传，?mapping={"列名":"标准字段"} 可覆盖自动映射
POST /api/imports/commit?token=xxx  # 确认导入
GET  /api/products/export?fmt=xlsx  # 导出当前产品库
```

## PDF / Word / 图片解析

属增强路线（P2）：解析结果一律先进入预览界面，**人工确认后**才能进入正式产品库，当前版本未实现。
