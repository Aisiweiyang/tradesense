# 18 · 单证工作台（货件 / 单证 / 异常 / 催补）

第四阶段新增模块：覆盖成交后的履约单证流程。与售前模块（询盘→报价）共用客户、产品、回复草稿、审计与组织隔离基础设施。

## 页面与流程

菜单「单证工作台」（`/shipments`）：三段式布局——顶部统计带（待处理/高风险/货件数）、左侧货件列表（风险优先排序）、右侧详情（标签页：异常 / 单证 / 字段对照 / 沟通记录）。

```
新建货件（或从询盘/报价转入）
  → 上传单证 PDF（发票/装箱单/提单/报关单/信用证/原产地证）
  → 数字 PDF 自动提取字段（记录页码+原文证据）
  → 规则引擎跨单证校验 → 生成异常队列
  → 逐条：采纳建议 / 已手动修改 / 忽略并说明（必填理由）/ 指派同事
  → 生成催补邮件草稿（引用具体异常，人工复制发送）
  → 全部解决后进入待发货
```

## 字段提取（证据机制）

- 仅处理**有文本层的数字 PDF**（pdfplumber）；扫描件/图片 PDF 标记为「待人工录入」（本阶段不做 OCR），提供结构化人工录入表单，录入值 `source=manual, confidence=1.0`。
- 每个提取字段记录：值、置信度、**页码（1-based）**、**原文行**。前端点击证据可打开 PDF 预览并跳到对应页（浏览器内建查看器 `#page=N`）。
- 已支持字段：Invoice/PO/B/L No.、Shipper/Consignee/Notify、HS Code、Quantity/Packages、Net/Gross Weight、CBM、Unit/Total Price、LC Amount、Incoterm、Ports、Vessel/Voyage/Container/Seal、ETD/ETA/Latest Shipment Date、多行 Description of Goods。

## 内置规则（确定性，可按客户停用/调参）

| 规则 | 判定 | 默认严重度 |
| --- | --- | --- |
| amount_vs_lc | 发票 Total Amount ≠ 信用证 LC Amount | 高 |
| lc_consignee | 提单收货人归一化 ≠ 信用证要求（TO ORDER OF …） | 高 |
| gross_weight_match | 装箱单毛重 vs 提单毛重，允差默认 ±0.5%（可配） | 中 |
| hs_code_match | 发票 vs 报关单 HS Code | 中 |
| goods_description | 品名归一化后不一致 | 低 |
| missing_docs | 必备单证缺失；截单 <24h 升级为高风险倒计时 | 中/高/低 |

- 配置：`GET/PUT /api/shipments/rules/{code}`，支持全局与客户级覆盖（客户级优先）。
- 自然语言建规则为受控 AI 场景（条件预览→人工确认），本阶段未开放入口，接口形态已预留。
- 规则执行失败不静默：解析失败的单证状态为 failed 并带原因，可单文件重传。

## 异常处理

- 状态机：`open → adopted（采纳建议，自动回写字段）/ manual_fixed / ignored（必填理由）/ resolved`；每次动作写审计日志。
- 重新校验（重传文件、人工改字段或点「重新校验」）会**自动清理不再成立的 open 异常**，人工已处理的记录永远保留。
- 催补邮件：逐条引用异常（期望值 vs 实际值）、插入缺失清单与截单时间，中英双语，明确标注需人工确认事项；**系统不发送**，人工复制到邮箱/WhatsApp。

## API 速览

```
GET/POST        /api/shipments
GET/PATCH       /api/shipments/{id}
POST            /api/shipments/{id}/documents        # multipart 上传（仅 PDF ≤20MB）
GET             /api/shipments/documents/{id}/file   # PDF 预览（支持 ?access_token= 供 iframe）
GET             /api/shipments/{id}/fields
PATCH           /api/shipments/fields/{id}           # 人工修正（触发重新校验）
POST            /api/shipments/{id}/recheck
POST            /api/shipments/issues/{id}/action    # adopt/manual_fixed/ignore/assign
GET/PUT         /api/shipments/rules[/{code}]
POST            /api/shipments/{id}/chase-email
```

## 已知边界

- 扫描件 OCR 未接入（路线图 P3）；当前依赖人工录入兜底。
- 单证类型识别：优先按文件名关键词，文件名无法识别时按内容标题兜底（COMMERCIAL INVOICE / PACKING LIST / BILL OF LADING 等，中英文均支持）；两者都未命中才归为 other。
- PDF 预览使用浏览器内建查看器 + 页码跳转；"点击字段画布内高亮原文"需 pdf.js 文本层方案（路线图）。
- 规则库为内置 6 条；自定义条件规则（受控 AI 预览）接口已预留未开放。
