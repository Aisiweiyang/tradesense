# 01 · 新手快速开始

目标：10 分钟内完成「导入产品 → 粘贴英文询盘 → 看懂需求 → 匹配产品 → 追问 → 报价 → 回复草稿 → 建跟进任务」完整闭环。

## 第 0 步：登录

启动后打开 http://127.0.0.1:5173 ，使用演示账号：

- 邮箱 `demo@tradesense-demo.cn`
- 密码 `demo1234`

演示数据里已有 42 个产品、16+ 条询盘（覆盖 10 种典型场景），可以直接体验。

## 第 1 步：导入你的产品（可选，演示数据可直接跳过）

进入 **产品 → 产品导入**：

1. 点击「下载模板」，用 Excel/CSV 按模板填写（支持中文表头：货号、品名、材质、阶梯价…）。
2. 上传后系统自动做**字段映射**（可人工调整）、逐行校验、识别重复 SKU。
3. 确认预览结果后点「确认导入」——只有通过校验的行会写入，错误行会明确列出。

> 阶梯价格填写示例：`500:3.2;1000:3.0;5000:2.8`（数量:单价，多档用分号分隔）。

## 第 2 步：粘贴一封英文询盘

进入 **询盘 → 粘贴/录入询盘**，把客户的原文粘进来（可点「填入示例询盘」体验）。系统立即：

1. 识别语言，生成**中文摘要**（客户要什么/数量/目的港/认证/交期/风险/建议下一步）；
2. 提取**结构化需求**：产品、材质、颜色、数量、目的港、贸易术语、认证、交期、目标价…；
3. 自动创建/关联客户档案。

## 第 3 步：看懂询盘工作台

询盘详情页从左到右：

- **概览**：中文摘要 + 完整度（已确认哪些、缺哪些、为什么还不能正式报价）；
- **对话**：客户后续回复直接粘贴进来，需求状态自动更新；
- **需求**：每个字段可人工修改、锁定（🔒 锁定后系统不会再自动改）；
- **追问**：系统只推一个最值得问的问题，并解释原因；
- **匹配**：点「运行匹配」得到候选产品，每条都显示满足/未满足/淘汰原因；
- **报价**：选产品+数量+术语 → 程序计算明细（每行有数据来源）→ 人工批准后才算正式报价；
- **回复**：10 类场景生成中英文草稿，标注事实来源和人工确认项；
- **跟进**：一键创建跟进任务。

## 第 4 步：每天怎么用

1. 打开 **工作台**：看「需要关注」和「今日到期任务」；
2. 打开 **今日待办**：处理超期/今日任务（可延期、完成）；
3. 收到新询盘：粘贴进来（或配置邮箱自动拉取），按工作台指引推进。

## 常见疑问

**Q：客户说 "any color is fine" 会怎样？**
需求状态里颜色会被标为「无要求」(unconstrained)，不再反复追问。

**Q：客户中途改数量/颜色？**
新消息会自动更新字段，旧值进入修改历史（如 `颜色: blue → black`）。

**Q：目标价低于成本？**
报价页会明确提示亏损风险，且该报价无法直接批准为正式报价（需先调价）。

**Q：系统的认证/关税提示可信吗？**
仅作业务辅助提醒，正式决策请咨询货代和专业机构（见「术语助手」页免责声明）。
