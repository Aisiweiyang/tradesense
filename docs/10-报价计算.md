# 10 · 报价计算

## 原则

**价格 100% 由确定性程序计算**（`services/quotation.py`），AI 不参与定价。每一行明细都标注数据来源（产品阶梯价 / 价格规则默认值 / 用户输入），并输出假设条件、缺失项与风险提示。

## 计算口径

```
基础成本   = 阶梯价(qty 落档)                        来源: SKU 阶梯价格表
EXW 成本   = 基础成本 + 包装/件 + 印刷摊销(封顶) + 模具摊销
FOB 成本   = EXW + (国内物流 + 出口报关)/qty
CIF 成本   = FOB + 国际海运/qty + 保险/qty
             海运 = 单重kg × qty × 区域费率(USD/kg)，最低按整柜零担起价
             保险 = 110% 发票金额 × 0.3%
CFR/DAP    = 对应子集；DDP = CIF + 目的国关税(默认 6%，仅估算)
汇率       = 报价币种汇率 × (1 + 缓冲 2%)   ← 仅真实跨币种时应用，USD→USD 不加缓冲
建议报价   = 成本(含税费) / (1 - 利润率)
合计       = 建议报价 × 数量
```

默认参数（机构可用 PriceRule 覆盖）：包装 $0.25/件、印刷版费 $60 摊销（封顶 $0.15/件）、国内物流 $280、报关 $180、保险 0.3%、汇率缓冲 2%、海运区域费率（EU 1.25 / NA 1.15 / ME 1.05 / OCE 1.35 / ASIA 0.8 / SA 1.5 / AF 1.7 / 默认 1.6 USD/kg，最低 $260）、DDP 关税 6%。

## 四类价格严格分离

| 字段 | 含义 | 客户可见 |
| --- | --- | --- |
| unit_cost | 内部成本底线 | ❌ 仅内部 |
| unit_price | 程序建议报价 | 可选 |
| customer_price | 业务员实际报给客户的价 | ✅ |
| （approved 后） | 正式报价 | ✅ |

## 版本与审批

- 同一询盘+产品重复创建 → 版本号 +1，旧版本自动 `superseded`；
- 修改客户价 → 清除旧审批人与审批时间，撤销 `is_formal`，转为 `pending_approval`；价格未变时保留审批；
- 已替代或已拒绝的报价不能改价或再次批准（409 `quote_closed`），需创建新版本；合并报价单同样不能重新批准关闭的版本；
- 拒绝或替代旧报价/报价单时撤销正式状态；重复批准当前已批准版本不会改写审批时间；
- `customer_price < unit_cost` → 自动转 `pending_approval` 且**拒绝批准**（below_cost）；
- 询盘存在报价阻塞项（缺必填字段/字段矛盾）时 `approve` 返回 409 `blocked_by_requirements`；
- 只有 `approve` 成功 → `status=approved, is_formal=true`，记录审批人与时间，写审计日志。

## 输出示例（FOB 1000 件）

```
产品成本(阶梯价)      $2.8000 /件   $2,800.00   来源: SKU TS-VB-001 阶梯价格表 qty≥1000
包装                  $0.2500 /件   $250.00     来源: 价格规则默认值
Logo 印刷(摊销)        $0.0600 /件   $60.00     来源: 版费 60 USD 按 1000 摊销, 封顶 0.15/件
国内物流(工厂→港口)    $0.2800 /件   $280.00    来源: 价格规则默认值
出口报关及单证         $0.1800 /件   $180.00    来源: 价格规则默认值
利润(15%)             $0.5972 /件   $597.18    来源: 默认利润率, 可在报价中调整
----------------------------------------------------------
内部成本 $3.570 | 建议报价 $4.17 | 合计 $4,170 | 有效期 30 天
风险: 运费与税率为程序内置估算值，正式报价前请以货代实时运价核对
```

## 与需求状态联动

- 缺单重/目的港/术语 → 明细标注 missing + 询盘阻塞项列表；
- 客户目标价低于建议价 → 风险提示「不建议低于成本报出」；
- 目标价 < 成本 → 亏损订单风险；
- 数量 < MOQ → 可协商提示；
- DDP → 必须人工核实税率与清关代理的强制风险提示。
