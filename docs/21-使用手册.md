# 21 · 使用手册（写给使用者的操作说明）

> 这份手册不讲代码，只讲怎么把系统用起来。目标读者：外贸业务员 / 团队管理者。
> 10 分钟快速体验看 [01-新手快速开始](01-新手快速开始.md)；本文是完整版。

## 一、这套系统是干什么的

一句话：把客户询盘变成可跟进、可报价、可核验的订单流程，中间所有"动脑子"的部分（价格、认证、一致性检查）都由程序算，AI 只给建议，**系统永远不会替你自动发消息**。

## 二、启动与登录

双击 `scripts\start_dev.bat`（Windows）或 `bash scripts/start_dev.sh`（macOS/Linux），脚本会自动装依赖、建库、灌演示数据，然后：

- 界面：<http://127.0.0.1:5173>
- 演示账号（二选一）：
  - `demo@tradesense-demo.cn` / `demo1234` —— 管理员，功能全开
  - `member@tradesense-demo.cn` / `demo1234` —— 业务员，部分操作受限

端口被占用时先设环境变量再启动（PowerShell）：

```powershell
$env:TRADESENSE_BACKEND_PORT = "18001"
$env:TRADESENSE_FRONTEND_PORT = "15173"
.\scripts\start_dev.bat
```

## 三、每天的流程

### 1. 询盘进来

左侧 **询盘 → 粘贴/录入询盘**，把客户原文（中英文都行）粘进去，点「创建并解析」。系统会自动：出中文摘要、抽取结构化需求（数量/颜色/目的港/认证/目标价…）、建客户档案、标记信息完整度。

也可以走渠道自动进来：**渠道连接** 页配置邮箱（IMAP）、WhatsApp、独立站表单或通用 Webhook（n8n/飞书等）。没配真实凭据时系统用**明确标注的模拟连接器**演示，不会假装已连接。同一封邮件重复推送会被自动去重。

### 2. 看懂询盘、追问客户

打开询盘详情：

- **概览**：完整度环告诉你"能不能报价、还缺什么"；
- **追问**：系统只推一个最值得问的问题，并解释"为什么问这个"；
- **对话**：客户的回复直接粘进来，点「添加并重新解析」，需求状态自动更新——改数量、换颜色都会记录历史；字段有矛盾（比如先说蓝色后说黑色）会标红提醒；
- **需求** 标签页可以人工改字段或上锁（🔒 锁定后系统不再自动覆盖）。

### 3. 匹配产品

**匹配** 标签页点「运行匹配」。每条候选都给出满足/未满足条件和淘汰原因；点「供应商比价」展开同产品的多家供应商成本/交期/可靠性对比，有推荐标记。

### 4. 报价

**报价** 标签页，选产品、数量、贸易术语、利润率：

- **成本来源** 可以选「产品阶梯价」，也可以选具体供应商的报价；
- 如果成本币种不是美元，表单里会显示当前生效汇率（来源是设置页维护的汇率表）；没配置会黄字提醒你去录入；
- 点「计算并创建草稿」，每一行成本都有来源说明；**内部成本只有你能看**；
- 价格没问题点「批准」才成为正式报价。低于成本的客户价会被拦截或转待审批。

### 5. 回复客户

**回复** 标签页：

1. 选场景（首次回复/追问/发报价/寄样…共 10 种）和语气；
2. 可以勾选 **知识库** 条目（比如"欧盟食品接触：LFGB"），生成时会把要点以引用块附在英文正文后，并标注来源；
3. 点「生成中英文草稿」，核对"使用的事实"和"发送前需人工确认"清单；
4. 点「批准」，然后点「复制英文全文」，去你的邮箱/WhatsApp 里**人工发送**。

### 6. 跟进

**今日待办** 和 **跟进任务** 会列出：超期未回、报价后长期沉默、高意向、信息不全、休眠客户待激活等，每条都带理由。

### 7. 数据看板

**数据看板** 顶部是九阶段销售漏斗（新询盘 → 有效线索 → 澄清中 → 已报价 → 寄样中 → 谈判中 → 已成交），显示触达数、阶段转化率和停留时长中位数；下面还有渠道来源、信息完整度分布。点漏斗任一阶段可以看统计口径说明。

## 四、成交之后：单证工作台

左侧 **单证工作台**：

1. 「＋ 新建货件」填订单号、港口、截单时间、必交单证清单；
2. 选中货件，「⬆ 上传单证（PDF）」上传商业发票、装箱单、提单、信用证等（只收 PDF；扫描件没有文字层的会标"待人工录入"）；
3. 同类单证传第二版会自动生成**新旧字段差异**；
4. 系统按内置规则自动找异常：金额不一致、提单 TO ORDER 不符、HS Code 对不上、毛重允差超限、品名矛盾、单证缺失——每条异常都有证据（单证名 + 页码 + 原文）；
5. 处理异常：采纳建议（自动回写字段）/ 标记已手动修改 / 忽略（要填理由）；也可以指派给同事；
6. 缺件或临近截单时可以生成催补邮件草稿（同样人工发送）；
7. 全部处理完，点右上角「⬇ 导出复核包」：下载一个 zip，内含每类单证最新版 PDF、中文核验报告（含异常和处理记录）、SHA-256 校验清单。这个包可以直接发给客户或存档。（此按钮仅管理员/经理可见）

## 五、设置

- **汇率（手工维护）**：填"基准币种 / 目标币种 = 汇率"（比如 USD / CNY = 7.2），报价跨币种时自动折算。币种对按字母序存储，反方向查询自动取倒数。不接外部实时汇率源。
- **系统状态 / AI 接入**：不配 AI 一切功能可用；想启用润色等增强能力，在 `backend/.env` 里配 openai_compat 或本地 ollama。

## 六、权限速查

| 操作 | viewer | member | manager | owner |
| --- | :-: | :-: | :-: | :-: |
| 看询盘/产品/看板/知识库 | ✓ | ✓ | ✓ | ✓ |
| 录询盘、跑匹配、生成草稿、建知识条目 | | ✓ | ✓ | ✓ |
| 改客户价、批准报价、批准报价单 | | | ✓ | ✓ |
| 产品/供应商管理、导出复核包、改汇率 | | | ✓ | ✓ |
| 用户与全局设置 | | | | ✓ |

越权操作会得到明确的 403 提示。

## 七、数据在哪、怎么重置

- 数据默认在 `backend\data\tradesense.db`（SQLite 单文件），上传的单证 PDF 在 `backend\data\documents\`；
- 想恢复出厂演示数据：关掉两个服务窗口，删掉 `backend\data\` 整个文件夹，重新运行 `start_dev.bat`；
- 换 PostgreSQL 生产模式见 [docs/03](03-Docker部署.md)。

## 八、常见问题

**AI 要配吗？** 不用，不配 AI 时所有核心功能可用（确定性模式）。

**系统会替我发邮件吗？** 不会。草稿批准后自己复制去发，这是设计红线。

**目标价低于成本怎么办？** 系统会在报价里标风险并拦截低价批准，最终判断由人做。

**忘记密码/加人？** 演示账号密码固定 `demo1234`。当前版本暂无改密和用户管理界面，正式使用需管理员直接在数据库更新密码哈希或建账号（权限矩阵已预留 user.manage，见路线图）。

**文术语缩写看不懂？** 左侧 **术语助手**，搜 FOB / MOQ / LFGB 都有中英解释。

## 九、必须知道的红线

1. 系统永不自动发送任何邮件/消息；
2. 正式报价必须人工批准；对外输出的报价单 PDF 不含内部成本；
3. AI 输出只是建议，发送前必须人工核对；
4. 运费/税率/汇率折算都是估算口径，正式报出前请自行核实。
