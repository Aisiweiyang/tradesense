# 05 · 外部渠道接入

所有渠道实现统一连接器契约，外部消息归一化为同一询盘模型：

```
health_check() / pull_messages() / normalize_message()
create_draft() / sync_status() / handle_webhook()
```

每条外部消息保存：渠道、外部账号、会话 ID、消息 ID、发送方、接收时间、原始内容、标准化内容、附件、内容哈希、处理状态、关联询盘。

## 幂等与恢复

- **消息级去重**：`(org, connector_account, external_message_id)` 唯一；
- **内容级去重**：同一外部会话内相同内容哈希只入一次；
- **同步游标**：每个账号独立 cursor，中断后从断点继续；
- **失败重试**：同步异常记录到账号 `last_error` 与同步日志，状态转 `error`，恢复后再次「立即同步」即可（有测试覆盖）；
- **绝不伪造连接**：缺凭据 = `mode=simulated` + `auth_state=not_authorized_simulated`，界面明确标注。

## 1. 手动录入 / 粘贴

始终可用的基础入口：询盘列表 →「粘贴/录入询盘」。

## 2. 邮箱（IMAP）

- 真实接入：创建连接器时填 `mailbox / host / port`，环境变量 `IMAP_PASSWORD`；
- 未配置时为**模拟邮箱**：内置演示邮件，点「立即同步」逐封拉取（演示完整管道）；
- 只读拉取、只生成草稿，**永不自动发送**；
- 生产可扩展 Gmail OAuth / Microsoft OAuth（适配器接口已预留）。

## 3. WhatsApp Cloud API

- Webhook 接入：`GET /api/webhooks/whatsapp/{account_id}` 完成 hub.challenge 校验，`POST` 接收消息；
- 消息按 Meta 标准载荷解析（`entry[].changes[].value.messages[]`）；
- 环境变量：`WHATSAPP_TOKEN`、`WHATSAPP_VERIFY_TOKEN`、`WHATSAPP_APP_SECRET`；
- 未配置时为模拟连接器，可用 curl 模拟推送（演示数据已含重复推送幂等场景）。

## 4. 独立站：表单 + 聊天组件

- 表单接口：`POST /api/public/webform/{account_id}`（JSON 或 form 字段均可）；
- 内置蜜罐字段（`website_url`/`_hp`）拦截机器人，内容过短拒绝；
- 可嵌入聊天组件：页面引入 `<script src="https://你的域名/api/public/widget/{account_id}.js"></script>`，右下角出现「Inquire / 询盘」按钮；
- 来源追踪：消息记录渠道与原始表单数据。

## 5. 第三方平台（阿里国际站 / 中国制造网）

- **不做任何未授权抓取**；
- 支持：平台转发邮件 → 邮箱连接器、平台询盘导出 CSV → 产品/询盘导入、或官方 API 适配器（接口已预留 `platform_csv` 类型）。

## 6. 自动化平台（n8n / Zapier / Make / 飞书 / 钉钉）

通用入站 Webhook：`POST /api/webhooks/generic/{account_id}`

```json
{ "id": "唯一消息ID", "sender": "客户邮箱或姓名", "text": "询盘正文" }
```

接受 `text|message|body|content` 字段，自动去重。n8n 示例：Webhook 节点 → HTTP Request POST 到上述地址。

## 同步日志

「渠道连接 → 日志」或菜单「同步日志」：每次拉取/推送/去重/失败全量留痕，最近外部消息的处理状态（processed/duplicate/failed）一目了然。
