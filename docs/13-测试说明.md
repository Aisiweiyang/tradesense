# 13 · 测试说明

## 运行

```bash
# 后端（79 个测试）
cd backend
.venv/Scripts/python -m pytest            # 或 python -m pytest

# 前端（11 个测试）
cd frontend
npm test
```

后端测试使用**内存 SQLite**（StaticPool），每个测试独立事务回滚，互不干扰；
场景测试 `test_demo_scenarios.py` 使用真实种子流程构建一次性文件库（测试后清理）。

## 端到端

`test_api.py::test_full_core_flow` 覆盖规格要求的完整链路：
导入产品 → 创建询盘 → 添加多轮消息 → 需求状态更新（black/1000/FOB）→ 匹配 → 追问 → 报价创建 → **人工批准为正式** → 英文报价草稿生成 → 创建跟进任务并完成 → 修改历史含 blue→black。

重复 Webhook 不产生重复询盘：`test_s10_webhook_duplicate_ingested_once` + `test_connectors.py` 去重组合。
AI 不可用核心可运行：整个套件即在此前提下通过。
