# 13 · 测试说明

## 运行

```bash
# 后端（242 个测试）
cd backend
.venv/Scripts/python -m pytest            # 或 python -m pytest

# 前端（36 个测试）
cd frontend
npx vitest run

# E2E（5 条链路，本地需前后端已启动；CI 中自动起服务）
E2E_TOKEN=<登录接口返回的token> npx playwright test
```

后端测试使用**内存 SQLite**（StaticPool），每个测试独立事务回滚，互不干扰；
场景测试 `test_demo_scenarios.py` 使用真实种子流程构建一次性文件库（测试后清理）。

## CI 与覆盖率

- GitHub Actions（`.github/workflows/ci.yml`）三 job：backend（pytest，services 覆盖率 >=85% 门槛）/ frontend（tsc + vitest + build）/ e2e（起 uvicorn + vite 跑 5 条 Playwright 链路）；
- 本地跑覆盖率：`pytest --cov=app/services --cov-report=term --cov-fail-under=85`（当前 87%）。
